# AOV identity assets

The GNU GPLv3 grant for AOV code does **not** grant rights to the official AOV name, logo, or icon as branding for another service. The following supplied identity files are excluded from that grant:

- `assets/aov-logo-source.jpg`
- `assets/aov-logo.png`
- `assets/aov-icon.jpg`
- `assets/welcome-host.jpg`

They are present so the official AOV project can be viewed and tested. If you publish or redistribute your own AOV installation or release package, replace these files with your own logo, icon, and welcome image and remove any claim that your service is the official America On Vibe site. The application code and other separately licensed assets remain reusable under their stated licenses. This identity policy does not restrict accurate statements that a fork is based on AOV.
