# America On Vibe (AOV)

AOV is an independent, noncommercial nostalgia project inspired by the AOL experience of the late 1990s. Its desktop-style windows, channel menu, ribbon, buddy list, chat rooms, instant messages, internal mail, and dial-up sign-on are meant to bring back the feeling of exploring an early online service in a modern browser. The official site is [americaonvibe.com](https://americaonvibe.com/). AOV is not affiliated with or endorsed by AOL.

The project owner designed and developed AOV with assistance from OpenAI Codex. Codex helped research options, write and revise code, create some project assets, and test changes; the owner directed the project and made the final design and release decisions.

## Local setup

1. Use PHP 8.2 or newer with SQLite, PDO MySQL, cURL, SimpleXML, OpenSSL, and mbstring. A web server and MariaDB are needed for chat. This project was developed with Windows 11 and XAMPP.
2. Run `composer install` in this checkout. The post-install script patches the pinned authentication package to use Argon2id where available. The resulting `vendor` folder belongs **outside** the public web root in production.
3. Copy [config.example.php](config.example.php) to `aov-private/config.php` in a private sibling folder outside the web root and fill in your own database, base URL, and optional SMTP settings. Never commit that private file.
4. Create a dedicated chat database and import [migrations/chat.sql](migrations/chat.sql). Grant its user only the database privileges needed by chat.
5. Serve the project through your web server. The private SQLite account database is created on first request. SMTP is used only for password recovery; AOV Mail remains internal.

This source tree has no member database, passwords, SMTP credentials, or production sessions. Review privacy and moderation requirements before inviting users to a public deployment. Kids Only is a static exhibit and has no child accounts or interactive features.

## Channels

Each channel is configured in [channel-configs](channel-configs). Edit its JSON to change feeds, subchannels, chat links, and crosslinks. The menu graphics are generated by `node scripts/generate-channel-buttons.js`. External article and forum links follow the destination site's embedding rules.
